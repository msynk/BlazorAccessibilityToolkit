# W3C ACT Rules test cases

The files in `testcases/` are copied unchanged from the test cases of the W3C Accessibility Conformance Testing (ACT) Rules (rules at <https://www.w3.org/WAI/standards-guidelines/act/rules/>); `.gitattributes` keeps git from changing their line endings. `act-testcases.json` is derived from <https://www.w3.org/WAI/content-assets/wcag-act-rules/testcases.json>: it lists only the test cases of the rules the toolkit's Razor analyzer implements, with fewer fields. `ActRulesTests.Update_the_test_case_snapshot` refreshes them.
